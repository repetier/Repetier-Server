# Repetier-Server 2.0.1

> [!IMPORTANT]
> **Repetier-Server 2.0.1 is free for everyone** – all features, for personal and commercial use,
> without a license key.
>
> Development of Repetier-Server has been discontinued. We may publish one or two bug-fix
> releases if serious bugs are reported. After that, there will be no further development.

## Highlights

- All features unlocked for everyone, no license key needed.
- Improved frontend design.
- Bambu Lab printers supported (beta).
- New webcam management supporting more webcam types and sources.
- Maintenance tasks and per-printer notes.
- Klipper: better time prediction, heightmap and named fans.
- Printer and server logs in the user interface.
- Folders for G-code storage.

## Important dates

- **30 June 2027:** The automatic update check and the Repetier-Informer push service are switched
  off. Repetier-Server keeps working after that date.
